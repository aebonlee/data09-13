### 차량 CAN 데이터 유효성 검증 Agent

직무 소속 : 차량 전장 기능품 개발 담당

해결하고 싶은 현안 : 최근 차량 내 통신(CAN 통신) 데이터의 오류가 있어, 실차 시험에서 로깅한 CAN 데이터의 유효성을 검증하는 Agent 구현

보유 데이터 유형 : 차량 내 CAN 데이터 정리 문서(CAN DBC - 엑셀 파일), 실제 차량 CAN 로깅데이터(TRC 파일 - TXT 유형 파일임)

기대산출물 : CAN 데이터 유효성 검증 보고서(전송 주기 오류, CRC 오류, ID 언매칭 등)

* 기능품 제조사 마다 데이터가 약간씩 상이해서, CAN DBC와 약간 다를 수 있는데, 이 부분도 체크 가능하게 하면 좋을 것 같습니다.
