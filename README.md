# data09-13 · 차량 CAN 데이터 유효성 검증 Agent

실차 시험 CAN 로그(TRC)를 DBC 엑셀 기준으로 검사해 전송 주기 오류·CRC 오류·ID 언매칭과 제조사별 편차를 보고서로 만드는 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 양승문 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 — 프로젝트 기획서 등록 (2026-09-28) |
| 다음 개발 | DBC 엑셀과 TRC 로그를 올리면 ID 언매칭·전송 주기·DLC 불일치를 검사해 보고서를 내는 브라우저 도구(CRC는 규칙 확보 후) |
