# data09-13 · 차량 CAN 데이터 유효성 검증 Agent

## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-13/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

사용 순서는 화면 위 메뉴 순서와 같습니다.

1. **DBC 기준표** — DBC 엑셀(xlsx·xls·csv)을 열고 시트·머리행·열(메시지 ID·이름·주기·DLC·송신 ECU)을 맞춘 뒤 「기준표 만들기」
2. **TRC 로그** — 실차 TRC 로그를 엽니다(PEAK PCAN 계열 TRC 1.0~2.1 형식)
3. **검증 보고서** — 허용 오차(%)를 정하면 ID 언매칭·전송 주기·DLC 불일치 결과가 나옵니다. 엑셀로 내보내거나 인쇄합니다.

실제 파일이 없으면 첫 화면의 **「예시 데이터 불러오기」** 를 누르세요. 가상 DBC·로그가 들어가고 화면 위에 「예시 데이터」 안내 띠가 표시됩니다. 예시에는 주기 이탈·프레임 누락·미정의 ID·누락 ID·DLC 불일치를 일부러 넣어 두었습니다.

- 파일은 **이 브라우저 안에서만** 읽고 계산합니다. 외부로 보내지 않습니다.
- DBC 기준표와 검사 설정은 이 브라우저(localStorage)에 남고, TRC 로그는 크기 때문에 저장하지 않습니다(다시 열면 다시 선택).
- 예시 파일: `samples/예시데이터_DBC.xlsx`·`예시데이터_DBC.csv`·`예시데이터_로그.trc` — 모두 가상 데이터입니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| DBC 엑셀 가져오기 | 완료 | xlsx·xls·csv, 시트·머리행 선택, 열 매핑(열 이름으로 미리 짐작), ID 16진수/10진수 표기 선택, 신호 줄이 여러 개인 표를 메시지 단위로 합침, 같은 ID 에 값이 다른 줄·읽지 못한 줄 안내, 기준표 엑셀 내보내기 |
| TRC 로그 파싱 | 완료(공개 형식 기준) | 머리말·주석 줄 건너뛰기, $FILEVERSION·$COLUMNS 인식(없으면 짐작), 버전 1.0~2.1, 표준/확장 ID, CAN FD 길이, 채널, 에러·원격·상태 줄 건수, 읽지 못한 줄 표시. 실제 샘플로 보정은 2단계 |
| ID 언매칭 검사 | 완료 | 로그에만 있는 ID(프레임 수), DBC 에만 있는 ID |
| 전송 주기 검사 | 완료 | ID별 평균·최소·최대·지터, 허용 오차(%) 사용자 지정, 이탈 구간(앞·뒤 시각, 간격, 짧음/김, 로그 줄 번호), 채널 선택 |
| DLC 검사 | 완료 | DBC DLC 와 실제 길이가 다른 프레임 수, 로그에 나온 길이별 건수 |
| 검증 보고서 | 완료 | 요약(항목별 이상 ID·건수) + ID별 상세표 + 이탈 구간표, 판정별 보기, 엑셀 내보내기(5개 시트), 인쇄 |
| CRC 검사 | 다음 단계 | 2단계 — CRC 규칙(위치·다항식·초기값·범위) 확보 후. 1단계는 에러 프레임 건수만 참고로 표시 |
| Alive Counter 검사 | 다음 단계 | 2단계 — 사용 여부 확인 후 |
| 제조사 편차 프로필 | 다음 단계 | 2단계 |
| 신호 값 범위 검사 | 다음 단계 | 3단계 |
| AI 요약 | 다음 단계 | 3단계 |
